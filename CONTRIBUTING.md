# Contributing to Parkify

Thanks for helping improve the Parkify prototype.

## Before opening an issue

- Search existing issues for the same problem.
- Include the affected part: gateway, slot 1 puck, slot 2 puck, or Android app.
- Describe the steps to reproduce and the behavior you expected.
- For hardware problems, include the board and sensor model, wiring, router channel, and relevant Serial Monitor output.
- Remove Wi-Fi credentials, private network details, and other secrets from logs and screenshots.

## Pull requests

- Keep changes focused and explain why they are needed.
- Preserve the Android application ID and namespace `com.quetra.parkingapp` unless the project owners explicitly decide to migrate them.
- Update the README when setup, hardware, API behavior, or supported scope changes.
- Do not commit build outputs, local IDE settings, or real network credentials.

## Development areas

- Flutter app: `app/`
- ESP8266 firmware: `firmware/`
- Project and setup documentation: `README.md`
